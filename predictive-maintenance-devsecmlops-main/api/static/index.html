Plant floor

Simulated machines stream sensor readings to the model in real time. As tools wear out, risk rises; with auto-maintenance on, a machine at high risk is serviced before it breaks down.

Events

    Batch scoring

    Score many machines at once, for example a nightly check of the whole plant. Use sample data or upload a CSV with the sensor columns.

    CSV columns: machine_id (optional), machine_type, air_temperature_k, process_temperature_k, rotational_speed_rpm, torque_nm, tool_wear_min. An actual_failure or machine_failure column, if present, is used to measure accuracy. The original AI4I 2020 dataset from UCI or Kaggle can be uploaded as-is.
